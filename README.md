# AI 대기지킴이

미세먼지 민간점검단을 위한 비산먼지 억제조치·대기배출사업장 감시 지원 앱입니다.

![AI 대기지킴이 소개](assets/ai-air-guardian-thumbnail-v1.png)

## 실행

`index.html`을 웹 브라우저에서 열거나 정적 웹 서버에서 실행합니다.

## 구성

- 비산먼지 억제조치 기준 및 사례
- 대기배출사업장 감시 참고 자료
- 보고문안 초안
- 사업 개요 및 준수 사항

법령·사진 출처와 적용 기준은 앱 내부에서 확인할 수 있습니다.

## 한국어 안내 음성

사례 설명은 한국어 전용 `ko-KR-SunHiNeural` 음성으로 제작했으며, 재생 속도는 기본보다 3% 낮췄습니다. 음성은 앱에 포함되어 재생할 때 별도 음성 생성 요청이 필요하지 않습니다. 자막과 법령 내용은 그대로 유지합니다.

`tools/refresh-korean-voice.py`는 기존 자막을 유지하면서 안내 음성을 다시 만드는 도구입니다. Python에 `edge-tts`를 설치한 뒤 실행하며, 생성 시 Microsoft Edge의 온라인 음성 서비스를 사용합니다.
