# AI 대기지킴이

미세먼지 민간점검단을 위한 비산먼지 억제조치·대기배출사업장 감시 지원 앱입니다.

![AI 대기지킴이 소개](assets/ai-air-guardian-thumbnail-v1.png)

## 실행

정적 웹 서버에서 폴더 전체를 제공합니다. 예: `python -m http.server 4186` 실행 후 `http://localhost:4186`에 접속합니다. 설치·오프라인 저장은 HTTPS 또는 localhost에서 지원됩니다. `index.html`과 `app.js`·`core.js`·`assets` 폴더를 함께 배포해야 합니다.

## 구성

- 비산먼지 억제조치 기준 및 사례
- 대기배출사업장 감시 참고 자료
- 보고문안 초안
- 사업 개요 및 준수 사항
- 작업명·법령 검색, 기기별 즐겨찾기, 조항별 공유 링크
- 공정·업종·도장 높이 조건을 반영한 계산기
- 감시 구분별 보고 임시저장, 직접 수정본 보존, TXT 내려받기
- 홈 화면 설치, 법령·그림·사진 오프라인 저장 및 선택 다운로드 음성 자료팩

법령·사진 출처와 적용 기준은 앱 내부에서 확인할 수 있습니다.

## 한국어 안내 음성

사례 설명은 한국어 전용 `ko-KR-SunHiNeural` 음성으로 제작했으며, 재생 속도는 기본보다 3% 낮췄습니다. MP3 파일은 설명을 재생할 때 불러오며, 별도 음성 생성 요청이 필요하지 않습니다. 오프라인 자료 화면에서 전체 음성 자료를 저장할 수 있습니다.

`tools/refresh-korean-voice.py`는 기존 자막을 유지하면서 안내 음성을 다시 만드는 도구입니다. Python에 `edge-tts`를 설치한 뒤 실행하며, 생성 시 Microsoft Edge의 온라인 음성 서비스를 사용합니다.

법령 기준은 2026.9.18 시행 법률 제21465호·시행규칙 제56호입니다. 2026.10.03 중요 기준을 표본 대조했으며 전체 조항을 법적으로 전수 검증한 것은 아닙니다. 사진 분류 제목만으로 개별 위반을 확정하지 않으며, 근거가 불충분한 사진 연결은 제외했습니다. 실제 AI 질의응답 API는 포함하지 않습니다.

변경 후 `node tools/check-regressions.cjs`로 계산기·매체 연결·음성 구간·오프라인 MP3 범위를 검증하고 `python tools/build-precache.py`로 캐시 버전을 재생성합니다. 실제 iOS/Android 설치·비행기 모드 동작은 실기기에서 별도로 확인해야 합니다.
